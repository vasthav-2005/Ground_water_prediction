Model Executive Summary

The predictive model utilizes an Extreme Gradient Boosting (XGBoost Regressor) framework trained on 51,985 6-hourly telemetry readings across 18 stations in Meghalaya, India. The engine yields 96.15% prediction accuracy and an R² score of 0.9657.

13-Feature Engineering Pipeline
Temporal Features: Year, Month, Day, Hour, DayOfYear
Autoregressive Lags: GWL_lag1 (6h), GWL_lag2 (12h), GWL_lag4 (24h)
Rolling Aggregations: GWL_diff_1, GWL_roll_mean_24h/48h, GWL_roll_std_24h
Station Identifier: Station_Code (Categorical 0-17)
Dual-Engine Cloud Architecture

Features a Zero-Dependency Pure Python JSON Tree Evaluator running on Vercel Serverless Functions ($0\text{ MB}$ native C++ binary overhead, $<1\text{ ms}$ evaluation latency).
